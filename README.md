# EcoSort AI

**Class 10 AI portfolio project** — image-based waste classification using a CPU-friendly TensorFlow transfer-learning model, with Orange Data Mining used for visual data analysis and model comparison.

## Important distinction
The uploaded `ecosort_ai.ows` workflow uses Orange Image Analytics embeddings (1,000 numerical features) with Logistic Regression and Random Forest. This Python app uses a separate MobileNetV2 transfer-learning pipeline. They are two experiments on the same dataset, not the same trained model. Do not claim Python reproduces Orange's exact model.

## 1. Add your dataset
Download and extract the Kaggle Trash Type Image Dataset:
https://www.kaggle.com/datasets/farzadnekouei/trash-type-image-dataset

Place the six class folders here:
```text
data/raw/
├── cardboard/
├── glass/
├── metal/
├── paper/
├── plastic/
└── trash/
```
If Kaggle extraction creates an extra enclosing folder, move the six class folders into `data/raw/`. The class folder names should be the class labels.

## 2. Setup (Windows / Python 3.10)
Open PowerShell in this project directory:
```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
No GPU is required. Training can take time on an 8 GB RAM CPU-only laptop.

## 3. Train the Python model
```powershell
.\.venv\Scripts\python.exe src\train_model.py
```
This creates:
- `models/ecosort_mobilenetv2.keras`
- `models/class_names.json`
- `reports/python_metrics.json`
- `reports/python_classification_report.txt`
- `reports/python_confusion_matrix.png`

The script uses a stratified directory-based training/validation split (80/20). This is separate from the Orange workflow's sampler and metrics.

## 4. Run the app
```powershell
.\.venv\Scripts\python.exe -m streamlit run src\app.py
```
Upload a JPG, JPEG, PNG, or WEBP image. The app shows the predicted class and model confidence.

## 5. Orange workflow
Open `orange/ecosort_ai.ows` in Orange Data Mining. If the dataset path in the saved workflow points to another computer, reopen **Import Images** and select your local extracted dataset. The Orange workflow is retained as a separate experiment. Export Orange's test predictions and metrics into `orange/exports/` if you want to compare both experiments.

## Project structure
- `src/train_model.py` — trains/evaluates the Python image model
- `src/app.py` — Streamlit image prediction app
- `src/common.py` — paths and image helpers
- `src/inspect_dataset.py` — checks folder counts and image readability
- `orange/ecosort_ai.ows` — supplied Orange workflow
- `reports/` — generated evaluation artifacts
- `docs/portfolio_report.md` — report template

## Academic integrity
Only report metrics generated by running the project. The Python and Orange metrics may differ because they use different feature extractors and model pipelines. This is a school project prototype, not a certified waste-sorting system.
